### M01.2 — Theorem A (exact distribution of the stability statistic, isotropic case)
- **Statement to prove:** Let x ∈ ℝᵈ fixed, r = ‖x‖ > 0, ε ~ N(0, s²I_d), d ≥ 2, ν = d − 1. Then
  Δ = cos(x, x+ε) = T / √(T² + ν), where T ~ noncentral‑t(ν, λ = r/s).
  Hence for θ ∈ (−1, 1): P(Δ < θ) = F_{t'(ν,λ)}( θ√ν / √(1−θ²) ).
- **Proof sketch to complete rigorously:** decompose ε = a·x̂ + b with a ~ N(0, s²), b ⊥ x̂, ‖b‖² ~ s²χ²_ν, a ⫫ b (rotational invariance). Then Δ = (r+a)/√((r+a)² + ‖b‖²). Define T = ((r+a)/s) / √(‖b‖²/(s²ν)) → noncentral‑t by definition. The map g(T) = T/√(T²+ν) is strictly increasing.
- **Done when:** full proof in `theory/thmA.tex` with every step justified (rotational invariance lemma, independence, definition of noncentral t).

### M01.3 — Corollaries: moments, asymptotics, anisotropic case
- **Action:** Prove/derive:
  1. **Small-noise expansion:** E[Δ] = 1 − (d−1)s²/(2r²) + O(s⁴/r⁴), valid only when (d−1)s²/r² ≪ 1. Contrast with the manuscript formula (C071, C077): it uses Tr(Σ) = d·s² instead of (d−1)s². More importantly, the expansion breaks down when (d−1)s²/r² isn't small.
  2. **High-dimensional limit:** if d → ∞ with (d−1)s²/r² → κ, then Δ → 1/√(1+κ) in probability (via ‖b‖²/(ν s²) → 1 and a/r → 0). Give a non-asymptotic concentration bound via Laurent–Massart χ² tails.
  3. **General Σ:** second-order expansion E[Δ] ≈ 1 − (Tr Σ − x̂ᵀΣx̂)/(2r²); concentration via Hanson–Wright; exact CDF as a ratio of quadratic forms, computed numerically (Imhof's method or Monte Carlo). State clearly that the closed form of Theorem A needs isotropy.
- **Output:** `theory/corollaries.tex`; table `tables/expansion_error.csv` comparing exact mean vs manuscript formula vs corrected expansion over a grid d ∈ {64, 384, 768, 1024}, (d−1)s²/r² ∈ {0.01, 0.1, 0.5, 1, 2}.
- **Done when:** proofs complete; table generated by script.

### M01.4 — Theorem B (two-sided detection guarantee; replaces Proposition 1)
- **Setting:** H0 (benign paraphrase): ε ~ N(0, s0²I); H1 (mutation): ε ~ N(0, s1²I), s1 > s0. Test: flag mutation iff Δ < θ.
- **Prove:**
  (a) **Exact operating characteristic:** θ_α = g(F⁻¹_{t'(ν, r/s0)}(α)) gives FPR = α exactly, and TPR(θ_α) = F_{t'(ν, r/s1)}(F⁻¹_{t'(ν, r/s0)}(α)).
  (b) **Optimality among cosine-based tests:** prove (or cite precisely, e.g. Lehmann & Romano, *Testing Statistical Hypotheses*) that the noncentral‑t family has monotone likelihood ratio in T with respect to λ. Then by Karlin–Rubin, the threshold test is UMP among tests that are functions of Δ, for H0: λ ≥ λ0 vs H1: λ < λ0.
  (c) **Information loss of cosine:** if both x_t and x_{t+1} are observed, ε is observed exactly and ‖ε‖²/s² ~ χ²_d is sufficient for s. The UMP test is then on ‖ε‖², **not** cosine. Derive the power of both tests at equal α, and plot the power gap vs d and s1/s0. Explain when cosine is still justified (scale invariance; normalised embeddings where only the angle matters). This is a real result and goes in the paper either way.
  (d) **Finite-sample high-probability guarantee (the honest "1−δ" statement):** using Laurent–Massart bounds, give an explicit θ and an explicit separation condition on (s1² − s0²) in terms of (r, d, δ0, δ1) such that FPR ≤ δ0 **and** FNR ≤ δ1 simultaneously. Constants must be explicit.
  (e) **Using the Lipschitz assumption (the manuscript states it but never uses it):** if for paraphrases d_sem(c, c′) ≤ η and ‖E(c) − E(c′)‖ ≤ L·d_sem, then ‖ε‖ ≤ Lη, so Δ ≥ √(1 − (Lη/r)²) whenever Lη < r (deterministic angle bound). Any θ below this gives FPR = 0 under H0. Combine with (a) for TPR under H1.
- **Output:** `theory/thmB.tex`; figures `figures/thmB_power_cos_vs_chi2.pdf`, `figures/thmB_roc_theoretical.pdf`.
- **Done when:** all five parts proven; auditor can follow each step.

### M01.5 — Theorem C (LLR verifier and three-way decision; replaces "decision-theoretically optimal")
- **Prove/state:**
  1. Under conditional independence of evidence sources given the truth value, and calibrated per-source likelihoods, posterior log-odds = prior log-odds + Σᵢ LLRᵢ (weights wᵢ = 1). The LLR test is Neyman–Pearson optimal for the simple binary test.
  2. Without independence, learned wᵢ via logistic regression on per-source calibrated log-odds give the minimum-log-loss model *within the linear-in-LLR class*. This is **not** NP-optimal in general. Say so in plain words.
  3. **Chow's rule with costs:** actions {say True, say False, abstain} with costs c_FP (say True when false), c_FN (say False when true), c_a (abstain). With p = P(true | c): say True iff p ≥ 1 − c_a/c_FP; say False iff p ≤ c_a/c_FN; else abstain. The abstain region is non-empty iff c_a < c_FP·c_FN/(c_FP + c_FN). In log-odds: τ1 = log((c_FP − c_a)/c_a), τ0 = log(c_a/(c_FN − c_a)). Derive fully.
  4. Optimality requires **calibration**; M05 measures calibration and reports where it fails.
- **Output:** `theory/thmC.tex`.
